Medidor de Botones - LibraryMaterialCard

Abre la página de Biblioteca en 320x700 (móvil) y 1024x768 (escritorio).

Luego ejecuta este script en la consola del navegador (F12 → Console):

Pasos para verificar:

MÓVIL (320×700):
  1. Abre DevTools (F12)
  2. Abre la pestaña "Console"
  3. Ajusta el viewport a 320×700 (DevTools → más opciones → "Device toolbar" o similar)
  4. Navega a Biblioteca
  5. Entra en una carpeta con 2+ archivos (ej: Química/Equilibrio químico)
  6. Escribe en la consola: window.measureLibraryButtons()
  7. Verifica: - openBtn debe estar visible (visible: true) y tener texto "Abrir" - upBtn y downBtn deben estar visible - Ninguno de los botones debe solaparse (bottom de título < top de botones)
ESCRITORIO (>620px, ej: 1024×768):
  1. Ajusta el viewport a 1024×768
  2. Escribe en la consola: window.measureLibraryButtons()
  3. Verifica: - openBtn NO debe estar visible (visible: false) o no debe existir - openBtnDesktop DEBE estar visible con texto "Abrir material" - upBtn, downBtn, compartido, favorito, descargar/eliminar deben estar en 2 filas

Cambios implementados:

• MÓVIL (≤620px): - Nuevo grid 3 columnas en .card-actions - Botón "Abrir" (action-open) en fila 1, columnas 2-3 (arriba derecha) - Botones "↑" y "↓" en fila 2, columnas 2-3 (segunda fila) - Texto del botón: "Abrir" (en lugar de "Abrir material") • ESCRITORIO (≥621px): - Ocultar action-open (móvil) - Mostrar action-open-desktop "Abrir material" - Layout original sin cambios
